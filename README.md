# WHYZEE NIGERIA LIMITED - Product Catalogue Platform

> Medical • Science • Technology | Educational & Healthcare Equipment Solutions

---

### 📖 Overview
A fully responsive product catalogue website built for **WHYZEE NIGERIA LIMITED**, a leading supplier of medical, scientific, and technological equipment for schools and hospitals in Nigeria.

The platform showcases 28+ product categories with a clean, commercial-grade UI focused on B2B enquiries.

### ✨ Key Features Built
- **Category Hero System:** Highlighted Laboratory Furniture & Fittings category with optimized layout (reduced from 460px to 280px for grid consistency)
- **Clean UI Refactor:** Removed heavy black gradient shadows and overlays, replaced with white cards, subtle borders (#E9E5F2) and soft purple shadows
- **Product Grid:** 3-column responsive grid with 28 product cards
- **Image Handling:** `object-fit: cover` for lab images, `contain` for equipment to prevent cropping
- **Enquiry Cart:** WhatsApp-integrated enquiry system for bulk product requests
- **Responsive:** Mobile-first, works on all screen sizes

### 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Custom Properties, Grid, Flexbox)
- **JavaScript:**  JS for cart and filtering
- **Styling:** No framework - pure custom CSS for performance
- **Deployment:** GitHub Pages

### 🔧 Problem Solved
Original hero card had:
- `height: 460px` - too large, broke grid flow
- `background: linear-gradient(transparent, rgba(0,0,0,0.9))` - heavy black shadow hiding content
- `opacity: 0.85` on images

**Fix Applied:**
- Reduced hero to `280px`
- Changed background to `#ffffff` with `border: 1px solid var(--border)`
- Removed overlay gradient, set text colors to `#111827` for readability on white

### 🚀 Deployment
Hosted on GitHub Pages from `main` branch.
